# Catatan Perubahan Proyek Kalkulator

## Praktikum 2

- Menambahkan petunjuk menjalankan program pada README.md.
- Memisahkan fungsi format_hasil ke dalam bantuan.py.
- Mengganti nama bantuan.py menjadi utilitas.py dan menyesuaikan
  perintah import pada kalkulator.py.
- Memperbaiki kesalahan penulisan pada fungsi format_hasil.
- Membuat dan menghapus catatan sementara melalui Git.
- Menambahkan .gitignore untuk mengabaikan cache Python,
  file log, dan file berekstensi .env.
- Menghentikan pelacakan debug.log tanpa menghapus file lokalnya.
- Menambahkan dua komentar pada kalkulator.py dengan mencoba
  staging sebagian menggunakan git add -p.
- Menambahkan aturan pengabaian folder venv dan file .tmp.
